# Stalker++ Browser Companion Extension (Chrome / Edge)

Human-in-the-loop OSINT clipper allowing you to send **public text snippets you are actively viewing** directly into your local Stalker++ workspace (`http://127.0.0.1:8000`) — without automated scraping, login bypassing, or CAPTCHA evasion.

## Install (Unpacked — 15 seconds)
1. Start Stalker++ locally on port `8000`.
2. Open `chrome://extensions` (or `edge://extensions`).
3. Enable **Developer mode** (top-right).
4. Click **Load unpacked** and select this `extension/` folder.
5. Highlight any public text on a page, click the **Stalker++** icon, choose your workspace, and click **Lưu vào Hồ sơ** or **Lưu + Phân tích**.
